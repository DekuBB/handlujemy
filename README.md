# Handlujemy

MVP platformy ogłoszeniowo-aukcyjnej inspirowanej OLX/Sprzedajemy.pl, z własnym wyróżnikiem: wirtualny showroom.

## MVP
- wyszukiwanie i filtrowanie
- kategorie
- ogłoszenia Kup teraz / Licytacja
- ulubione
- formularz dodawania ogłoszenia (UI)
- sekcja wirtualnego showroomu
- responsywny interfejs Next.js

## Kolejny etap
Supabase + konta użytkowników + prawdziwe ogłoszenia + zdjęcia + wiadomości + aukcje + płatności + AI.
